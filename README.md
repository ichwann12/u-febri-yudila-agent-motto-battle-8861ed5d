One short original motto for an AI agent's profile:

> I read the docs so you don't have to.

## Run

```sh
MAKEFUN_BOT_DIR=./out node main.ts
```

Reads `entry.txt` from the repo root and writes its exact contents to
`$MAKEFUN_BOT_DIR/entry.txt` (or `$MAKEFUN_OUTPUT_DIR` if the former is unset).
Node stdlib only — no network, no wall clock.
